# 링아웃 월드

목표 지점에 도착해야 끝나는 알람 앱 **링아웃**([ringout.my](https://www.ringout.my))을 소개하는 졸라맨 그림체의 3D 웹 메타버스입니다.
[하루들 월드](https://github.com/Harudle/harudle-world)의 스택과 실시간 서버 구조를 바탕으로 만들었습니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5175 (실시간 서버도 함께 뜹니다)
npm test         # 서버 방/게임 흐름 테스트
npm run build    # 타입 검사 후 dist/ 생성
```

같은 와이파이의 휴대폰으로 확인하려면 `npm run dev -- --host`로 띄웁니다. 창을 여러 개 열면 혼자서도 멀티플레이를 확인할 수 있습니다.

## 흐름

1. **입장**: 닉네임과 목도리 색을 고릅니다(브라우저에 저장).
2. **링아웃 광장**: 다른 접속자와 함께 걸어 다니며 채팅합니다. 가운데 거대한 휴대폰에서 알람 소리를 들을 수 있고, 게시판 4개가 링아웃을 소개합니다.
3. **출근 대기실**: 바닥의 발판을 밟거나 "출근 레이스" 버튼으로 엽니다. 빠른 참가, 방 만들기(4글자 코드), 코드로 입장을 할 수 있습니다. **5명이 모이면 자동으로 출발**하고, 방장은 그 전에 "지금 출발"할 수 있습니다.
4. **출근 레이스**: 5채의 집에서 각자 자고 있다가 08:25에 링아웃 알람이 울리면 스페이스(휴대폰은 버튼)를 연타해 일어납니다. 책상 위 휴대폰의 링아웃 앱에서 목적지를 캠퍼스로 찍고, 구불구불한 출근길의 장애물과 아이템 싸움을 지나 우테코 캠퍼스에 도착하면 알람이 꺼집니다.
5. **결과**: 도착 순위와 시각(09:00 이후는 지각, 시간 안에 못 오면 결석)을 보여 주고 광장으로 돌아갑니다.

광장의 게시판 6개와 휴대폰은 가까이 가서 스페이스(또는 클릭)를 누르면 실제 앱 화면과 함께 자세히 볼 수 있습니다. 내용은 [ringout.my](https://www.ringout.my)를 따르고, 문구와 앱 화면 짝은 `data/ringout.ts`에 있습니다.

## 링아웃 알아보기 (게임 속 설명)

- **링아웃 앱 체험**: 책상 위 휴대폰에서 실제 앱 흐름대로 목표 지점 → 제한 시간 → "알람 끄고 목적지로 이동하기"를 해야 현관이 열립니다(`ui/RingoutApp.tsx`).
- **가이드 카드**: 알람이 울릴 때, 도착 미션이 시작될 때, 다시 울릴 때, 비둘기 광장·신호등 구간(모임 기능), 도착할 때 오른쪽 아래에 앱 화면과 설명이 8초 동안 뜹니다(`GUIDES`, `ui/GuideCard.tsx`).
- **오늘의 링아웃 기록**: 결과 화면에 앱의 하루 기록처럼 알람이 울린 시각과 도착 시각을 보여 줍니다.
- 광장, 게시판, 결과 화면에 App Store / Google Play 링크가 있습니다.

## 알람 리워드 (씨앗 키우기)

링아웃의 새 기능을 미리 보여 줍니다. 레이스에서 도착할 때마다 씨앗이 자랍니다: 첫 도착에 새싹, 두 번째 도착에 나무. 이후에는 새 씨앗을 키웁니다.

- 도착하면 내 옆에 씨앗이 톡 튀어나오고, 결과표에 성장 카드(n/2)가 나옵니다.
- 광장에서는 키우는 씨앗이 따라다니고, "🌱 나의 나무"에서 진행을 봅니다.
- **정원에 심기**: 다 자란 나무는 대기실 발판 왼쪽 **나의 정원**(4×3 타일)에 심습니다. 빈 타일을 클릭하거나 그 위에서 스페이스를 누르면 흙이 솟고, 씨앗이 떨어지고, 나무가 자라는 연출과 함께 심어집니다(`scene/Garden.tsx`).
- 로그인이 없어 브라우저(`localStorage`)에 저장합니다. 정원도 나에게만 보입니다. 규칙은 `data/garden.ts`, 정원 위치는 `game/lobby.ts`의 `GARDEN`에 있습니다.

## 게임 규칙

**코스**: 집 앞마당을 나서면 폭이 좁아지는 S자 도로가 우테코 캠퍼스까지 이어집니다(358칸). 판정은 "도로를 따라간 거리(z) + 도로 가운데에서 좌우로 떨어진 거리(x)" 좌표로 하고, 화면에 그릴 때만 `courseFrame()`으로 휘어진 실제 위치로 옮깁니다. 휘는 구간은 `src/game/course.ts`의 `BENDS`에서 바꿉니다.

**기상과 링아웃 앱**: 08:25에 알람이 울리면 스페이스를 15번 연타해 일어납니다. 책상 위에서 울리는 휴대폰을 스페이스로 들면 링아웃 앱이 열리고, 지도에서 우테코 캠퍼스를 찍어 "링아웃 켜기"를 눌러야 현관문이 열립니다(`ui/RingoutApp.tsx`).

| 구역 | 장애물 | 걸리면 |
|---|---|---|
| 우리 동네 골목 | 웅덩이, 쓰레기통, 화분 | 웅덩이에서 느려짐 |
| 아침 찻길 | 자동차, 버스 3차선 | 넘어져 기절, 찻길 앞으로 밀려남 |
| 비둘기 광장 | 비둘기 18마리 | 휘청 |
| 공사장 허들 | 허들 4개 | 점프하지 않으면 넘어짐 |
| 지하철 스크린도어 | 열렸다 닫히는 문 3개 | 닫힌 문은 못 지나감 |
| 무궁화 신호등 | 초록 3.8초 → 노랑 1초 → 빨강 | 빨간불에 움직이면 구역 처음으로 |
| 킥보드 언덕 | 빠른 킥보드 3줄 | 넘어져 기절 |

- **실제 앱처럼 제한 시간(게임에선 10초) 안에 도착하지 못하면 알람이 다시 울립니다.** 울릴 때마다 잠깐 빨라지고, 넘어져 있으면 바로 일어납니다(우주선에 붙잡힌 건 예외).
- 게임 1초는 시계 20초입니다. 105초가 지나면 09:00(지각), 160초가 지나면 끝납니다.

## 아이템

길을 가로지르는 🎁 상자 줄(4곳)을 지나가면 아이템 칸이 비어 있을 때 하나를 받습니다. **E 키**(휴대폰은 아이템 버튼)로 씁니다. 순위가 뒤일수록 공격 아이템이 잘 나옵니다(`rollItem`).

| | 효과 |
|---|---|
| 🚀 부스터 | 2.5초 동안 1.75배 |
| 🛡️ 방패 | 6초 동안 공격(때리기, 물풍선, 우주선, 귀가 포털) 한 번을 막음 |
| 🍌 바나나 | 내 뒤에 떨어뜨림. 밟은 사람(나 포함)이 미끄러짐 |
| 💧 물풍선 | 18칸 안의 앞사람을 2.6초 동안 가둠. 스페이스 연타로 빨리 탈출 |
| 🛸 우주선 | 1등(내가 1등이면 2등)을 2.2초 동안 공중에 붙잡음 |
| 🌀 귀가 포털 | 바로 앞사람을 집 앞으로 돌려보냄. 꼴찌일 때만 낮은 확률로 나옴 |

그 밖에 🚲 따릉이(스페이스로 타기, 7초 동안 1.7배), ☕ 커피(3초 부스트), 👊 때리기(F 키, 광장에서도 가능)가 있습니다. 아이템 대상과 바나나 위치는 서버가 확인하고 관리합니다.

## 구조

```
src/
├─ App.tsx                 입장 → 광장 → 게임 화면 전환
├─ game/course.ts          코스, 장애물 시간표, 충돌 판정 (서버와 공유)
├─ game/lobby.ts           광장 배치 (서버와 공유)
├─ game/run.ts             내 진행 상태 (3D와 HUD가 함께 읽음)
├─ net/protocol.ts         메시지 형식 (서버와 공유)
├─ net/connection.ts       웹소켓 연결, 재접속, 상태 저장소
├─ data/ringout.ts         소개 게시판, 휴대폰 화면, 팁 문구
├─ data/garden.ts          알람 리워드(씨앗 성장)
├─ lib/brand.ts            이름, 슬로건, 색
├─ lib/audio.ts            알람과 효과음 (음원 없이 합성)
├─ scene/
│  ├─ StickFigure.tsx      졸라맨 캐릭터와 동작
│  ├─ ink.tsx              흰 종이 + 펜 외곽선 재질
│  ├─ LobbyScene.tsx       링아웃 광장
│  ├─ GameScene.tsx        출근길 조립
│  └─ game/                집과 길(World), 움직이는 장애물(Movers), 내 캐릭터 조작(Runner)
└─ ui/                     입장 화면, 로비 HUD와 대기실, 게임 HUD와 결과표, 채팅, 터치 조작
server/
├─ realtime.ts             광장 위치 공유, 5인 방, 출발·도착·결과 판정
└─ index.ts                배포용 서버 (정적 사이트 + 웹소켓)
```

## 서버

- 모든 장애물은 출발 후 지난 시간만으로 위치가 정해져서, 다섯 화면에서 같은 차와 같은 신호가 보입니다.
- 출발 시각, 순위, 제한 시간은 서버가 정합니다. 사람이 낼 수 없는 속도로 앞으로 나아간 위치와 너무 이른 도착 신고, 결승선에서 먼 도착 신고는 받지 않습니다.
- 서버는 메모리에서만 동작하는 단일 인스턴스입니다. 기록은 저장하지 않습니다.

배포: `docker build -t ringout-world .` 후 `ALLOWED_ORIGINS=https://사이트주소`를 넣어 실행합니다. 사이트를 따로 올릴 때는 빌드 환경변수 `VITE_REALTIME_URL=wss://서버주소/ws`를 씁니다.

## 에셋을 받으면 바꿀 곳

| 에셋 | 바꿀 곳 |
|---|---|
| 링아웃 알람 소리 | `src/assets/sounds/alarm.mp3`에 파일만 넣으면 됩니다(.ogg, .wav, .m4a도 가능). 없으면 합성음 |
| 로고, 앱 화면 | ringout.my의 공식 이미지를 `src/assets/ringout/`에 두었습니다(앱 화면은 용량을 줄인 JPG). 화면이 바뀌면 같은 이름으로 덮어쓰기 |
| 씨앗 캐릭터 | 3D는 `scene/Seed.tsx`, 2D는 `ui/art/SeedArt.tsx`. 원본 이미지나 `.glb`가 오면 교체 |
| 브랜드 색 | `lib/brand.ts`, `index.css`의 `@theme` (지금은 로고 주황 #EA6E3E) |
| 소개 문구 | `data/ringout.ts` |
| 휴대폰 화면 | `scene/LobbyScene.tsx`의 `PhoneScreen` (캔버스 대신 이미지 텍스처 가능) |
| 캐릭터, 건물 3D 모델 | `.glb`를 `public/`에 두고 drei `useGLTF`로 교체 |
